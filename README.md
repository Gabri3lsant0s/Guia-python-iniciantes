### **Guia Python para Iniciantes**



Projeto pessoal para praticar Python e registrar minha evolução nos estudos.



###### **Como executar**



1. Abra o terminal na pasta do projeto.
2. Execute:



**py main.py**



3\. Digite o número da opção desejada no menu.



###### **Conteúdos estudados**



* Funções
* Listas e dicionários
* Condições com if, elif e else
* Laços de repetição com for e while
* Classes e objetos
* Entrada de dados com input()
* Desafio de palíndromo

###### **Desafio de palíndromo** 

Um palíndromo é uma palavra ou frase que permanece igual quando lida de trás para frente.



Exemplos: 

* arara
* ana
* radar
* osso
